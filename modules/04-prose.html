Module 4

Steering it with plain language

The programming language here is your own.

Reframe "programming" for this room: they already know how to write the instructions. What they do not know yet is that writing them down, once, in a file, is the entire technique.

Two places to write the rules

A prompt is not a question. It is a setup: you prepare the ground, you don't query an archive.

Standing rules

Apply to every request. Safety, house style, vocabulary, what to never do.

This request

The job in front of you: context, objective, style, tone, audience, format.

Write once, applies always. Write now, applies here.
The six task-prompt elements are CO-STAR (GovTech Singapore): Context, Objective, Style, Tone, Audience, Response. Name it only if someone asks - the acronym costs more attention than it returns with this audience. The distinction that matters is the two scopes, not the mnemonic.

What it looks like

# Standing rules
- always cite the catalogue reference
- never invent provenance data
- uncertain fields: leave blank, flag [TO BE VERIFIED]

## This request
- Context: an auction lot description
- Objective: a coin catalogue entry
- Style: professional, concise
- Audience: collectors and buyers
- Response: 4 lines + condition grade

# the behaviour is now readable by a person

Plain text in a file. No code.

Why it matters

The thing that controls the machine is the same thing a new colleague reads to learn the job.

Markdown is just text with a bit of structure - headings, dashes. Say that once, do not teach it. The real point is the second card: this file is simultaneously the configuration and the documentation. For an SME with staff turnover, that is the sales pitch.

Skills and tools

Skill — how it works

A saved way of working, loaded when it fits the request. Written in the same plain language.

Tool — what it can do

A concrete action: open a PDF, read a spreadsheet, send a request. Result comes back as context.

Skills package your judgement. Tools give it hands.
A skill is triggered by its description matching the request - "grill me" loads a critique flow. Worth one line: this deck's own repository is built with skills, so the method is demonstrated by the thing they are looking at. Tools handle PDF, XLSX, DOCX, PPTX, CSV, images and audio - relevant because their material is all PDFs and photographs.
